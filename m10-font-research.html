How the pick was made: the complaint was the current face reading like a marketing product — a display face doing chrome work. The cure is a face designed for tool interfaces at 11–13px. Geist is exactly that (Vercel's developer-product face, Swiss-plain, SF-adjacent metrics), and with bundling on the table it adds a chosen identity that plain system SF doesn't. SF Pro system stays the zero-cost native runner-up — picking it means deleting the M3 font override and shipping stock. The airiness worth keeping from the current look survives in the color hierarchy — dim secondary text, whisper levels, translucent rail — which none of this touches. Apple's HIG bars Light-weight UI text on macOS, which rules out re-creating the light-shift with any face. The editor's monospace (Liga SFMono Nerd Font) is untouched.
